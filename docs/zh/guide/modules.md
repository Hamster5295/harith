# 模块

目前已实现 2 大类模块：
- [`UInt`](/zh/uint/)：通用无符号整数计算，适用于低位宽到高位宽。
- [`Fp`](/zh/fp/)：通用浮点计算，主要适用于 IEEE 标准与标量计算。

## UInt

无符号整数数据通路在参数化的操作数位宽上进行计算，并通过 `UIntAdd` / `UIntMul` / … 接口报告其延迟。

- **Add**：围绕共享加法器接口的位级进位结构：行波、进位跳过、先行进位、进位选择、全并行前缀网络（`PrefixStyle`），以及推断出的 `+`（宏加法器）。流水化的前缀与行波变体将进位链切分到寄存块中。
- **Mul**：部分积生成后进行归约：进位保存阵列、改进的 Booth radix-4 编码、由 Dadda/Wallace 树归约的 AND（或 Booth）部分积，以及推断出的 `*`。流水化的阵列与树变体对归约过程进行寄存。
- **Fma**：有效数乘积与加数通过单一进位结构合并；包含组合、Booth、树和推断变体，以及流水化版本。
- **Div**：迭代式逐位递归除法器：恢复余数、不恢复余数，以及 radix-2 / radix-4 SRT。

## Fp

浮点数据通路支持 IEEE-754 二进制格式，并可参数化配置操作数与结果格式，覆盖 `Fp64`、`Fp32`、`Tf32`、`Fp16`、`Bf16`。因此，混合精度运算可直接配置 Fp 模块实现。  
数值行为由 `FpPolicy`（`ftz`、`daz`）控制，并通过 `FpFlags`（`nv`、`dz`、`of`、`uf`、`nx`）返回结果。按照 RISC-V 规范，NaN 始终为 *Canonical NaN*。

共享基类（`FpAddBase`、`FpMulBase`、`FpFmaBase`）只实现一次解码、对齐与舍入，并将宽整数加法委托给 `uint` 计算模块执行。

- **Add**：解码两个操作数，将有效数对齐到公共工作指数，用带符号宽加法器相加，最后舍入并打包。各个不同实现变体主要在 *UInt 加法器*有所差异。
- **Mul**：将尾数相乘、指数相加，然后舍入并打包。各个不同实现变体主要在 *UInt 加法器*有所差异。
- **Fma**：精确乘积与对齐后的加数只做一次舍入求和。各个不同实现变体主要在 *UInt 加法器*有所差异。
- **Div**：带 `Decoupled` 请求和 `Valid` 结果的迭代恢复除法器；商每周期生成一位并精确舍入。
- **Convert**：解码并重新舍入到目标格式。转换器覆盖 `Fp64`、`Fp32`、`Fp16` 和 `Bf16` 之间的所有有向格式对。

流水线变体仅在内部对宽整数数据通路进行流水化；浮点控制是一个与数据通路延迟匹配的寄存器队列，因此 `stages` 等于最终延迟。`stages = 0` 使变体变为组合逻辑。
