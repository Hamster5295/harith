# 舍入模式

每个浮点单元都接收 3 位 RISC-V `rm` 输入，并据此对结果进行舍入。编码遵循 RISC-V 的 `frm` 字段。

::: info 源代码
`src/main/scala/fp/FpUtils.scala`
:::

## 编码

| `rm` | 名称 | 行为 |
| --- | --- | --- |
| 0 | RNE | 就近舍入，平局取偶 |
| 1 | RTZ | 向零舍入（截断） |
| 2 | RDN | 向下舍入（向负无穷） |
| 3 | RUP | 向上舍入（向正无穷） |
| 4 | RMM | 就近舍入，平局取最大幅值 |
| 5, 6 | — | 保留 |
| 7 | DYN | 动态（读取 `fcsr`）；这些单元不支持 |

## 说明

各单元解码 `0..4`；`5..7` 按截断处理。`rm` 是每个单元的运行时端口，因此不属于 [`FpPolicy`](/zh/fp/misc/FpPolicy)。
