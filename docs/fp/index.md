# Fp

Floating-point datapaths. Every module is exposed for the four formats `Fp64`, `Fp32`, `Fp16` and `Bf16` (same-format operands and result); the converters cover every directed format pair.

- **[Mul](/fp/mul/)** — 5 modules
- **[Div](/fp/div/)** — 1 module
- **[Fma](/fp/fma/)** — 7 modules
- **[Convert](/fp/convert/)** — 2 modules
