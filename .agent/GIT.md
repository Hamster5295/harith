# Git

This file provides instruction on git operations


## When

Agents are **required** to do considerable `git commit`s when files are edited to fulfill a specific purpose, i.e. implementing a specific function, fixing a bug, refactoring a module, etc.  

The commits **should** be one purpose at a time.


## Messaging

The commit messages should follow the format below:
- feat: some new features
- fix: a weird bug
- refactor: some renamings
- build: modification to build system and profile
- ci: continous integration
- chore: something else

The commit messages **must** use English
